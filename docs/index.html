How it works

Two copies. That's the whole workflow.

1

Open the panel

Click the ⇄ icon in your menu bar. A small floating panel appears and stays on top of whatever you're reading.

2

Copy old, copy new

Select the old text anywhere and press ⌘C. Select the new text and press ⌘C again.

3

Read the diff

Removed characters show in red strikethrough, added ones in green, with a count at the top. Copy something else to compare it against the last one.

Small on purpose

Made for the moment a diff tool tells you a long line changed, but not what changed inside it.

Character-level precision

Spots a single changed digit or a swapped word inside a paragraph of otherwise identical text.

Ignores line wrapping

Text copied from a wrapped web page compares cleanly — line breaks and repeated spaces are collapsed before comparing.

Inline or side by side

One merged view for reading, or OLD and NEW as two columns when you want the full before-and-after.

Always on top

The panel floats above your browser or editor, follows your light or dark appearance, and hides with one click.

Editable inputs

Paste or type directly into the OLD and NEW boxes, swap them if you copied in the wrong order, or clear and start over.

Private by design

Everything runs on your Mac. It reads the clipboard only while the panel is open, stores nothing, and never touches the network.

Install

Requires an Apple Silicon Mac (M1 or later) on macOS 12 or newer, and the Xcode Command Line Tools — already present if you use Homebrew or Git. If not, run xcode-select --install once.

  1. Download the zip and unzip it.
  2. Drag DiffPeek.app into your Applications folder.
  3. Open Terminal and make the launcher executable (needed once, because zip downloads lose this flag): 
    chmod +x ~/Applications/DiffPeek.app/Contents/MacOS/DiffPeek
  4. Double-click DiffPeek. The first launch compiles the app from its source — a few seconds — then the panel opens and the ⇄ icon appears in your menu bar.
macOS may block the first launch because the app isn't signed with a paid Apple developer certificate. Click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway. This only happens once.

Prefer the Dock? Turn on Show in Dock in the ⚙ Options menu. To start it with your Mac, add it under System Settings → General → Login Items.

One file of Swift

The entire app is DiffPeek.app/Contents/Resources/DiffPeek.swift — AppKit and WebKit, no dependencies. A launcher script compiles it with swiftc on first run and again whenever the source changes, so editing that file and relaunching is the whole development loop. The diff itself is a classic longest-common-subsequence comparison on characters, with prefix/suffix trimming and a fallback to word and line level for very large inputs.
